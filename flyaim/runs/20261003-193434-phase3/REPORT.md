### 视觉输入端的真实性声明

**`visual_input_fallback = False`**,策略:`superclass:ol_sensory`。

视觉输入驱动的是数据集内**真实存在的感光细胞群**(`superclass == 'ol_sensory'`)。但这仍不等于完整的生物视觉系统,须注意以下边界:

- 编码器决定「像素 → 小眼照度」的映射方式,**这一步是人为设计的**;
- 数据集未提供感光细胞的光谱敏感曲线与增益,色通道映射为近似;
- 下游的 lamina/medulla 处理虽由真实接线图承载,但**神经元模型是 LIF 简化模型**,不含真实电导、递质动力学与神经调质细节。

## 7. 限制与方法学声明

1. **视觉前端的第一步是人为设计的**:即使驱动的是真实感光细胞群,「像素 → 小眼照度/色通道」的映射方式仍由编码器决定,不含果蝇真实的光谱敏感曲线。
2. **神经元模型是 LIF 简化模型**:连接组只给出「谁连谁、连多强」,不含真实膜电导、递质释放动力学与神经调质扩散。
3. **连接组权重未被修改**;任何学习只发生于读出层(若 `readout.mode == "trained"`)。
4. **动作语义是人为定义的**:DN 活动到「左右/上下」的映射由开发者设定,不是果蝇真实的运动映射。真实 DN 与转向的对应关系需要行为学实验才能确定。
5. 本实验是**离线自建靶场**,不涉及任何真实游戏客户端或在线对战。
6. 报告中的 p 值为配对 t 检验;若 scipy 缺失则退化为正态近似(小样本下偏乐观)。
